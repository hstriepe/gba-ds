GBA DS

A Game Boy Advance with a second screen. The game plays on one screen; the other shows the game's own map, kept current as you explore, the way the DS Castlevanias do it. Games without a map use it in other ways (Mario Kart's race HUD, Tony Hawk's goal sheet), and the rest show their logo there.

The second screen

  • View › Stacked (⌘D) puts the second screen under the game, View › Side by Side (⇧⌘D) beside it. The checked one is on; choose it again to turn the second screen off, and the window shows the game alone.
  • View › Swap Screens (⇧⌘X) trades the two places. With the second screen off, it shows the map instead of the game for a moment.
  • View › Size (⌘2–⌘5) sets the window to that many times the GBA's screen; you can also drag its edges. Enter Full Screen (⌃⌘F) fills the display. Around the picture is plain black; the pause menu's Display › Overlays can add GBA DS's bezel.
  • The window has no frame around the picture: move the mouse to its top and the title bar with its buttons comes up, and goes again 2 seconds after the mouse leaves. View › Borderless Window (⌘B) takes the title bar away altogether; the window then floats above other windows and you drag it from anywhere. View › Lock Aspect Ratio keeps the window in the screens' shape as you resize it. In full screen the pointer hides when the mouse rests. While a game runs, the display doesn't go to sleep.
  • The map is taken from a hidden second copy of the game about once a second and after each room change; the game you play is never paused for it. Before the first map, and on title screens, the second screen shows the logo.

Your choices are remembered for next time.

Sound

GBA games mix their music at a low rate, which leaves a hiss and a harsh edge above it. As in GB App Builder's GB Player, the Mac version filters that out (and a slight hum below hearing), tuned to each game's own rate; Settings › Audio › Clean up GBA music turns it off.

Hotkeys: hold Esc and press S to save the quick state, A to load it, ↑ to swap the screens, ↓ for the LCD shader, Z or Return to quit. (They are GBA DS's hotkey button, HOME, with R, L, Up, Down, B and Start; change them in the pause menu.)

Game controllers work as soon as they're connected: the face buttons by position, the shoulders as L and R, the triggers for rewind and fast-forward, the Home or Guide button for the pause menu.

Saves

  • The game's own battery save is kept as you play, as on the cartridge. In an app made by GB App Builder it is the same file the app's GB Player version uses (~/Library/Application Support/mGBA Games/<game>/saves/), and in one made by Yoshi the same file as its Yoshi Player version (~/Library/Application Support/Yoshi/<game>/saves/), so you can switch between the two.
  • When you quit, GBA DS saves where you are and picks up there next time (the pause menu can turn this off). Ten save state slots are in the pause menu.
  • Save states are mGBA's own format: mGBA loads them, and GBA DS loads mGBA's.
